# Geo-Garbage

Geo-Garbage es una aplicación web para reportar y gestionar microbasureros georreferenciados.

## Tecnologías
- React
- Vite
- JavaScript
- ESLint

## Objetivo
Facilitar el registro y seguimiento de reportes relacionados con la acumulación de residuos.

## Ejecución del proyecto
1. Instalar dependencias: npm install
2. Iniciar el entorno: npm run dev
3. Validar el código: npm run lint
4. Generar compilación: npm run build
